# Seed Avatars

These raster PNGs are demo seed-data avatars for local development and
non-production demo records. They are copied into report attachment storage by
`app.scripts.seed_demo_records` and `app.scripts.backfill_seed_demo_photos`.

## Humans

Files: `humans/human-01.png` through `humans/human-10.png`

Source style: Open Peeps by Pablo Stanley.

Downloaded as raster PNG exports from DiceBear's Open Peeps API. DiceBear lists
the style as a remix of Open Peeps by Pablo Stanley, licensed under CC0 1.0.

License: CC0 1.0 Universal / public domain dedication.

## Pets

Files:

- `pets/pet-cat-01.png`
- `pets/pet-cat-02.png`
- `pets/pet-cat-03.png`
- `pets/pet-dog-01.png`
- `pets/pet-dog-02.png`
- `pets/pet-dog-03.png`

These are project-owned raster seed assets created specifically for Beacon demo
data. They intentionally use minimal line illustration, restrained flat fills,
and neutral expressions so pet records are visually distinct from human records
without introducing an unrelated third-party avatar pack.
